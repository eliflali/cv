EXHIBIT A

The Architectural Stack Matrix

Engineered for speed, offline reliability, and SEO metadata control.

Supabase Serverless DB

Couples' wedding invitations experience highly concentrated traffic spikes when invitations are dispatched. To ensure sub-millisecond response times under heavy concurrent loads, Doku utilizes a serverless Supabase connection pool integrated with Postgres Database Functions. This architecture processes dynamic guest RSVP writes and dietary checkoffs concurrently with direct PL/pgSQL database execution, avoiding cold-start API gateways.

// RESPONSE METRIC: SUB-MILLISECOND TRANSACTION LIFETIMES

Next.js SSR Metadata Engine

Modern wedding communication is highly collaborative. When sharing dynamic invitation links on messaging platforms (WhatsApp, Telegram, Instagram), generating flawless rich-link previews (displaying couple names and cover images) is critical. We designed a server-side rendering (SSR) rendering cycle in Next.js that parses request URIs and pre-injects OpenGraph meta tag schemas into the document payload prior to DOM rendering, guaranteeing 100% dynamic rich-previews.

EXHIBIT D

Guest Comfort Registry

Providing functional, architectural warning systems built to anticipate guest requirements on the dynamic invitation sheets.

Weather Alert System

Syncs with real-time location weather APIs. Couples can toggle notifications to alert guests of sudden downpours, offering suggestions like huddling under espresso awnings in Berlin.

Stiletto/Heel warnings

Alerts guests of the physical reception terrains. Warns attendees if the location features gravel walks, stone plazas, or grassy gardens to coordinate footwear.

Dietary Preference Maps

Processes and hashes allergen criteria. Allows guests to log options (Vegan, Celiac, Halal) to populate live kitchen dashboards for catering teams.
