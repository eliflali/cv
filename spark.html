EXHIBIT C

Engineering Blueprint

Architecting high-fidelity, animation-heavy experiences utilizing React Native CLI and native rendering paths.

60 FPS

Direct Thread Isolation

Dynamic UI animations bypass the React Native JS thread entirely. By utilizing declarative native UI configurations via the Reanimated library, frames execute directly on the UI main thread, guaranteeing flawless 60 FPS rendering under heavy canvas loads.

CLI

Direct Native Framework (No Expo)

Pure Objective-C and Swift bridges. Avoiding Expo packaging allows custom native module creation for core canvas renders, precise custom haptics controllers, and minimal build size footprint.

<100ms

Secure Offline-First Synchronization

Encrypted local SQLite storage with direct delta sync replication pipelines. Intimacy data is synchronized via end-to-end encrypted WebSockets in less than 100 milliseconds upon partner connection, ensuring immediate presence indicators.

Dynamic Intimacy Engine

A map of the high-fidelity render tree utilized during micro-discoveries inside the iOS client.

01 // Gesture Recognition (CoreHaptics API)

Captures physical contact. Touch vectors on the frosted heart trigger localized haptic pulses mimicking heartbeats.

02 // Native Animation Driver (CoreAnimation bindings)

Bypasses the virtual DOM. Direct GPU computation for backdrop filters, frosted card scaling, and Klimt gold glows.

03 // SQLite Cache Layer (SQLCipher Encryption)

Secure offline write buffer. Entries are locally committed, fully hashed, and staged for replication queues.

04 // WS Synced Bridge (Secure WebSockets)

Dispatches JSON payloads containing timestamped data offsets. Instantly unlocks peer nodes in secondary devices.
